1. Conceitos Fundamentais

Por que salvar dados e por que usar a instrução with open()?

Persistência de Dados

Variáveis na memória RAM desaparecem quando o programa fecha. Salvar em arquivo garante que as informações fiquem gravadas no disco rígido permanentemente.

O Poder do with open()

O gerenciador de contexto with garante que o arquivo seja fechado automaticamente assim que o bloco terminar, prevenindo corrupção de dados e vazamento de memória.

Uso de Funções

Encapsular o código de salvamento em uma função evita repetição (princípio DRY) e permite salvar dados de qualquer lugar da sua aplicação com apenas uma linha.

Salvar Texto Simples (.txt)

Ideal para logs, mensagens, anotações e conteúdos corridos.

def salvar_texto(caminho_arquivo: str, conteudo: str, modo: str = 'w') -> None:
    """
    Salva uma string em um arquivo de texto (.txt).
    :param caminho_arquivo: Nome ou caminho do arquivo (ex: 'log.txt')
    :param conteudo: O texto a ser gravado
    :param modo: 'w' para sobrescrever, 'a' para adicionar ao final
    """
    with open(caminho_arquivo, modo, encoding='utf-8') as arquivo:
        arquivo.write(conteudo + '\n')
    print(f"✅ Sucesso: Texto salvo em '{caminho_arquivo}'.")

# --- Exemplo de Uso ---
mensagem = "Relatório Diário: Todos os sistemas funcionando perfeitamente."
salvar_texto("diario.txt", mensagem)
salvar_texto("diario.txt", "Nova linha adicionada no final.", modo='a')

Salvar Estruturas Complexas (.json)

Ideal para Dicionários e Listas (preserva tipos de dados).

import json

def salvar_json(caminho_arquivo: str, dados: dict | list) -> None:
    """
    Salva um dicionário ou lista em formato JSON.
    :param caminho_arquivo: Nome do arquivo (ex: 'aluno.json')
    :param dados: Dicionário ou Lista do Python
    """
    with open(caminho_arquivo, 'w', encoding='utf-8') as arquivo:
        # indent=4 deixa o arquivo formatado e legivel
        # ensure_ascii=False garante acentos corretos (ç, á, ã)
        json.dump(dados, arquivo, indent=4, ensure_ascii=False)
    print(f"✅ Sucesso: Dados JSON salvos em '{caminho_arquivo}'.")

# --- Exemplo de Uso ---
aluno = {
    "nome": "Mariana Silva",
    "idade": 21,
    "cursos": ["Python", "Banco de Dados"],
    "ativo": True
}
salvar_json("aluno.json", aluno)

Salvar Dados Tabulares (.csv)

Perfeito para tabelas acessíveis no Excel ou Google Planilhas.

import csv

def salvar_csv(caminho_arquivo: str, cabecalho: list, linhas: list, modo: str = 'w') -> None:
    """
    Salva uma tabela em formato CSV.
    :param caminho_arquivo: Nome do arquivo (ex: 'notas.csv')
    :param cabecalho: Lista com nomes das colunas ['Nome', 'Nota']
    :param linhas: Lista de listas contendo os valores
    :param modo: 'w' sobrescreve, 'a' adiciona novas linhas
    """
    # newline='' impede a criacao de linhas em branco extras no Windows
    with open(caminho_arquivo, modo, newline='', encoding='utf-8') as arquivo:
        escritor = csv.writer(arquivo)
        
        # Grava o cabecalho apenas se estiver criando um arquivo novo (modo 'w')
        if modo == 'w' and cabecalho:
            escritor.writerow(cabecalho)
            
        escritor.writerows(linhas)
    print(f"✅ Sucesso: Tabela CSV salva em '{caminho_arquivo}'.")

# --- Exemplo de Uso ---
colunas = ["Nome", "Nota 1", "Nota 2", "Situação"]
estudantes = [
    ["Ana Souza", 9.5, 8.0, "Aprovado"],
    ["Bruno Lima", 6.0, 5.5, "Recuperação"]
]
salvar_csv("turma.csv", colunas, estudantes)

3. Comparativo Importante: Modo 'w' vs 'a'

Entenda a diferença crucial do parâmetro de abertura do arquivo.

modo = 'w' (Write) Sobrescreve

Apaga o conteúdo anterior!

Se o arquivo já existir, o modo 'w' limpa totalmente o conteúdo que estava lá dentro e grava o novo texto do zero.

open("arquivo.txt", 'w') # Apaga tudo -> Escreve novo
modo = 'a' (Append) Anexa ao final

Preserva o histórico!

O modo 'a' abre o arquivo posicionando o cursor no final. O novo conteúdo é adicionado ao final sem apagar o que já existe.

open("arquivo.txt", 'a') # Mantém tudo -> Adiciona ao fim
